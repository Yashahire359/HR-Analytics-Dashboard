# 📊 HR Analytics Dashboard | Power BI

## 📌 Project Overview

The HR Analytics Dashboard is an interactive business intelligence project developed using Microsoft Power BI to analyze employee data and understand workforce trends, employee attrition, and organizational performance.

This dashboard transforms HR data into meaningful insights through interactive visualizations and key performance indicators (KPIs), helping HR professionals make data-driven decisions.

## 🎯 Project Objectives

- Analyze employee demographics and workforce distribution.
- Monitor employee attrition and retention trends.
- Evaluate department-wise employee distribution.
- Understand employee job satisfaction.
- Identify workforce patterns and trends.
- Support strategic human resource decision-making.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and KPI calculations
- **Data Visualization** – Interactive charts and reports

## 📈 Key Performance Indicators (KPIs)

Depending on the metrics implemented in the report, the dashboard may include:

- Total Employees
- Total Employee Attrition
- Attrition Rate
- Average Employee Age
- Department-wise Employee Distribution
- Job Satisfaction
- Employee Demographics

## 📊 Dashboard Features

### 1. Employee Overview
Provides an overview of the workforce and employee demographics.

### 2. Attrition Analysis
Helps analyze employee attrition patterns and identify potential retention challenges.

### 3. Department Analysis
Provides insights into employee distribution across different departments.

### 4. Job Satisfaction Analysis
Helps explore employee satisfaction levels, where the relevant data is available.

### 5. Interactive Visualizations
Uses charts, graphs, filters, and slicers to explore HR data dynamically.

## 💡 Business Benefits

- Improves visibility into workforce trends.
- Helps identify employee retention challenges.
- Supports HR planning and reporting.
- Enables data-driven workforce decisions.
- Simplifies HR data analysis through interactive dashboards.

## 🚀 How to Use

1. Download or clone this repository.
2. Install Microsoft Power BI Desktop.
3. Open the `.pbix` file in Power BI Desktop.
4. Configure the data source if prompted.
5. Refresh the data if the source files are available.
6. Explore the report using the available visuals, filters, and slicers.
